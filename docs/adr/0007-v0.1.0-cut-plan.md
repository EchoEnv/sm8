# ADR-007: v0.1.0 cut plan + RFC §12/§13 conformance gaps

> **⚠️ Historical snapshot (2026-08-15).** The `Connector` SDK surface referenced here
> (including `ConnectorContractSpec`) was removed by ADR-011-a. Data-source
> conformance is now validated by per-connector `EngineProvider` test
> suites. Read current architecture from
> `docs/rfcs/2026-08-12_v1_architecture-spec/` + `docs/adr/0011-a-*`.

**Status:** Accepted. **Date:** 2026-08-15. **Author:** SM8 agent (post-PR #68 review; v2 fixes 10 issues raised in self-review).

## Context and Problem Statement

Per `agile-kindling-beacon.md` line 392 ("first `0.1.0` tagged") + RFC §13 DoD:

> *"At least one reference adapter and one reference plugin exist and pass conformance tests."*

After PR #68 (typed `realize(url)`) merged, the v0.1.0 freeze is structurally in place:

- ✅ `sm8-platform` pure transport (no ServiceLoader, no reflection)
- ✅ `sm8-server` deployment module (typed realize call, JVM shutdown)
- ✅ All 13 modules + 3 connectors enforce `bannedDependencies=org.apache.spark:*` mechanically
- ✅ All 3 connectors (`in-memory`, `spark`, `trino`) pass `ConnectorContractSpec`
- ✅ Reactor 843 green, real-JVM smoke verified

**However**, RFC §13 DoD has TWO halves — reference adapter + reference plugin conformance.
The adapters are covered; **the plugins are not**. None of the 6 reference plugins
(`audit`, `broadcast`, `cache`, `materialize`, `row-cap`, `skew`) extend
`HookContractSpec` or `PluginContractSpec`. Each plugin ships its own **standalone**
spec (independently verified by *reading*), but the unified contract is **not
structurally enforced**.

This is a **letter-vs-spirit gap**:

- **Letter**: each plugin has tests that exercise the same rules; the conformance is verified by inspection.
- **Spirit**: a 7th contributor adding a new reference plugin could skip the unified check (no compile-time enforcement); a refactor of `PreHook` / `Plugin` in `sm8-core` could silently break the contract rules.

PR-D closes the spirit gap by making the conformance **structural** (compile-time inheritance).

Additionally:
- `connectors/spark-connector/PortableExprCompiler` test density on aggregate/filter/derived-metric paths needs an **audit**, not a presumption of gaps.
- `MCPEngineProvider.query` replay-safety is not asserted (needed for PR-C-final-int follow-up).
- MiMa gate remains commented out (only required at the release-tag step).

## Decision

Add three pre-tag PRs (PR-D, PR-E, PR-F) to close the conformance gaps, then cut
the `v0.1.0` tag (PR-G) with MiMa re-enabled.

### PR-D — Conformance unification on the 6 reference plugins

Each plugin ships:

```
plugins/<name>-plugin/src/test/scala/io/sm8/plugins/<name>/<Name>ContractSpec.scala
```

…that extends `io.sm8.sdk.contract.HookContractSpec` (asserts: non-empty name,
priority in reserved range, correct stage wireName, `context.request` unchanged
after `run(ctx)`, fail-fast on throw) and `PluginContractSpec` (asserts: plugin
name non-empty, setup idempotent, hooks/adapters registered).

Each spec supplies the abstract members: `preHook`, `postHook`, `baselineContext`,
`plugin`, `engine` (5–10 lines per plugin).

**Tests added:** ~30 (4–5 per plugin × 6 plugins). **Behavior change:** NONE —
pure structural inheritance; the per-plugin hand-rolled specs already exercise
the same rules.

### PR-E — Spark `PortableExprCompiler` Expr-case coverage audit

Two-step pass:

1. **Audit**: run existing `PortableExprCompilerSpec` and produce a per-`Expr`-case coverage report.
2. **Fill**: add `forAll`-style tests for any `Expr` case under-tested.

Cases enumerated: literals (int, long, double, string, bool, null), refs
(field, dimension, measure), binary ops (`+`, `-`, `*`, `/`, `mod`,
`concat`), casts (int↔long, double↔decimal, string→timestamp),
`AggregateFn` (sum, avg, count, min, max, countDistinct),
`Predicate` composition (and/or/not/leaf), derived-metric composition
(measure refs + arithmetic).

**Tests added:** ~10–15. **Behavior change:** may surface 1–2 compiler bugs
(fix-in-same-PR if ≤ 5 LOC; defer otherwise).

### PR-F — Replay-safety / determinism audit (per-provider strategy)

Per-provider `*ReplaySafetySpec`:

```scala
// InMemory (case-class return — structural equality is correct)
test("query is deterministic for identical input") {
  val a = provider.query(model, request, ctx)
  val b = provider.query(model, request, ctx)
  a shouldBe b
}

// Spark (case-class return after collect() — Either equality is structural,
// but assert NO UDFs / accumulators / time-dependent sources by construction)
test("query is replay-safe (no UDFs, no accumulators, no time-dependent sources)") {
  // 1. assert the test data + query are free of these by inspection
  // 2. assert: a shouldBe b on the PortableQueryResult case class
}

// Trino-stub (FeatureDeferred always returns Left — trivially deterministic)
test("FeatureDeferred is deterministic by construction") {
  val a = provider.query(model, request, ctx)
  val b = provider.query(model, request, ctx)
  a shouldBe b
}
```

**Tests added:** 3 (one per provider). **Behavior change:** NONE — verifies
an invariant, not adds behavior.

### PR-G — v0.1.0 release cut

1. Bump `pom.xml` `0.1.0-SNAPSHOT` → `0.1.0` in **14 files** (parent + 13
   reactor modules — verified via `find . -name pom.xml -not -path "*/target/*"`).
2. `mvn install` — full reactor green.
3. Re-enable MiMa gate in `sm8-core/pom.xml` (lines 158–178 currently
   commented). First tag will assert no binary-compat violations vs.
   `previousVersion = 0.1.0`.
4. Tag `v0.1.0` on `main`. Push tag.
5. Update Plan §378 DoD checkbox ("first `0.1.0` tagged" → ✅).

### Layer ownership (per RFC §3 + adapters.md + hooks.md)

This decision does NOT change layer ownership. Confirmed and reaffirmed:

| Concern | Layer |
|---|---|
| Model shape, Expr, Predicate, FilterSpec | **core** |
| Filter / aggregate / derived-metric *execution* | **connector** |
| Transform (rename, unit conversion) | **hook** (`post:execute` mutator) |
| Metrics emission, audit, broadcast | **hook** (observer/side-effect) |
| Schema discovery | **connector** |
| Caching, persistence (`MaterializePolicy`) | **plugin** (hook) |

## Consequences

**Positive:**
- RFC §13 DoD fully satisfied (reference adapters AND reference plugins pass conformance *structurally*, not by inspection).
- Future contributors cannot skip the unified conformance check (compile-time inheritance).
- `PreHook` / `PostHook` / `Plugin` refactors in `sm8-core` cannot silently break contract rules.
- Spark `PortableExprCompiler` edge-case coverage makes the PR-B aggregate/derived-metric paths trustworthy.
- Replay-safety invariant makes the future PR-C-final-int (Docker RestateRunner) viable.
- v0.1.0 tag is release-ready; MiMa gate prevents silent binary-compat breaks for early consumers.

**Negative:**
- 3 PRs before the tag = 3 review cycles. Per the user's review cadence, this is acceptable.
- PR-E may surface 1–2 compiler bugs. Fix-in-same-PR is the cheap option; defer-to-follow-up if non-trivial.

**Reversibility:** Tag is irreversible; the 3 PRs before it are each reversible individually (the conformance tests are additive; no behavior changes).

## Alternatives Considered

1. **Skip the conformance tests, tag now.** Rejected: violates RFC §13 DoD spirit; future regression risk.
2. **Make conformance tests optional / opt-in.** Rejected: defeats the contract.
3. **One mega-PR covering PR-D + PR-E + PR-F.** Rejected: 3 reviewable units are cheaper than one giant diff; per karpathy "smallest correct change".
4. **Bump pom.xml to `0.2.0` to avoid MiMa `previousVersion` ambiguity.** Rejected: the plan line 392 says "first `0.1.0` tagged"; user reaffirmed `0.1.0`.
