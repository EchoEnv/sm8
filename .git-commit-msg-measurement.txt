feat(cli): sm8 rollup-report — the refusal-measurement read surface (ADR-0027)

The rollup lane shipped end-to-end (#345 staleness, #346 grain,
#347 observability, #349 routing invocation). The counters exist on
the wire (GET /metrics, port 9090) but reading them meant eyeballing
raw Prometheus text. This lands the single-command measurement view:
which refusal reason dominates, each reason's share, and a data-driven
hint for the next pick (algebraic migration vs more rollups vs grain
defaults — the exact decision the #349 arch review asked telemetry
to answer).

CLI only — zero server, zero core, zero platform changes:
- `sm8 rollup-report` fetches /metrics, parses the Prometheus text
  exposition with a hand-rolled no-regex parser (~30 LOC; HELP/TYPE
  and blanks dropped, values as Long, malformed lines tolerated),
  filters to the sm8_rollup_* family, renders the ranked report:
  scalar totals (rewrites/refusals/permanent), per-reason ranking
  with integer shares, dominant reason + a per-reason next-action
  hint (algebraicStateNotWired -> state migration; noGroupSetMatch
  -> more rollups; rollupSchemaStale -> rollup-refresh; ...).
- `--json` prints a flat sorted name->value map (cron/dashboard
  consumption, same global-option convention as the rest of the CLI).
- `--metrics-url <base>` (+ SM8_METRICS_URL env) — the metrics
  endpoint lives on its own port (9090 default), not the MCP URL.
- Client.get gains a baseUrl-override overload (the metrics port is
  a different endpoint than the MCP server).

PRE-EXISTING DEFECT FIXED in passing: sm8-cli's scalatest-maven-plugin
had NO <execution> binding — the plugin never ran, so
CliIntegrationSpec (the CLI's only test surface) was silently skipped
in every `mvn test` on main. The pom now binds the test goal to the
test phase (same shape as the spark-connector pom); both
CliIntegrationSpec and the new RollupReportSpec run and pass.

Tests (RollupReportSpec, real HTTP harness like CliIntegrationSpec):
parser golden-body + malformed-line tolerance, ranked ordering +
integer shares, empty state, --json flat map, non-200 exit 1,
garbage-body parse tolerance. Full sm8-cli suite green — including
CliIntegrationSpec's previously-skipped tests.

ADR-0027 documents the decision (CLI-only reader; MCP tool and
Restate-service alternatives rejected).
